# QQ Bot 学习通助手

接入现有 OneBot 11 反向 WebSocket，Cloudflare Workers 和 OneBotSession Durable Object 运行，无需单独启动 Python 服务。

## 私聊命令

- /help：私聊和群聊均显示图片菜单；图片生成或发送失败时自动改发文字。
- /register 手机号 密码 或 /register+手机号+密码：登录并开始监听。机器人先提醒撤回，再向超星发起登录。密码不会保存、回显或写日志。
- /location 纬度 经度 地址：保存用户提供的位置，定位签到携带 latitude、longitude、address、ifTiJiao=1；不是自动获取 GPS。更换位置请重新设置。
- /status：图片展示状态。
- /stop、/start：暂停、继续。
- /unregister：删除该 QQ 的登录会话、位置、去重记录和待发通知。

注册仅私聊有效，群内误发立即提醒撤回且不登录。不能保证 QQ 客户端、OneBot 实现及其日志不保留原始消息，机器人提醒撤回不等同于自动撤回。

## 监听与通知

每个 Bot 最多 20 个账号；会话、用户位置、最近 200 个活动结果和待发通知保存在该 Bot 的 Durable Object 私有存储。依赖平台静态加密，不额外保存密码，也不将登录会话暴露给网站 API。删除 DO 数据会同时丢失账号。

群定时提醒创建时只写入 D1 并立即回复确认；到期时再生成卡片，避免字体或 S3 请求阻塞命令响应。超过 3 秒的命令会先发“正在处理”，图片链路失败则发送文字。无法识别的斜杠命令和提醒格式都会给出用法，不再静默忽略。

每次任务检查一个到期账号，最多遍历 10 门根目录课程，超过 10 门轮转检查。每个账号目标间隔 60 秒，每个 Bot 的下一项任务最少间隔 5 秒，实际延迟随账号数、课程数及网络变化。课程列表每 15 分钟刷新。使用原有 DO alarm 调度，现有每分钟 Cron 兜底唤醒启用的 Bot；不保证即时监听或很短窗口内签到。

普通签到和已配置位置的定位签到自动提交。拍照、扫码、手势、签到码等发送图片提示在学习通完成，不绕过验证。只有上游返回 success 才提示签到成功，其他结果明确提示核对。先保存结果再发图片；QQ 断开时保留通知，恢复后重试。平台提交与本地存储之间不存在跨服务事务，极端中断时可能再次请求同一签到；QQ 发送响应丢失也可能导致重复通知。

登录过期需要重新 /register；网络错误退避到最多 15 分钟。为了不保存密码，不做密码自动重登录。

## 接口依据与验证边界

签到协议参考 MIT 项目 https://github.com/cxOrz/chaoxing-signin （停止维护），许可证见 chaoxing-third-party.txt。AES-CBC 登录参数参考 https://github.com/LnYo-Cly/ChaoXingAutoSign/blob/main/login.py 的公开协议；没有复制该 Python 源码。

自动测试使用模拟学习通响应验证凭据处理、坐标编码、命令隔离、签到去重与通知重试。没有真实学习通账号和正在进行的签到用于端到端验证，不能保证超星未公开接口仍兼容或允许 Cloudflare 出口 IP。遇到验证码、接口变更或上游限制会返回失败提示，需要实际联调。
